# Parivahan Sathi

Voice-first AI assistant for Indian RTO services (DL renewal, vehicle transfer, address changes).

**Demo prototype with synthetic mock data. Not affiliated with Parivahan Sewa, MoRTH, or Government of India.**

## Status

Scaffolding in progress — see `BUILD_LOG.md` after Phase 5.

## Quick start

```bash
npm install
cp .env.example .env.local   # add your OPENAI_API_KEY
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
